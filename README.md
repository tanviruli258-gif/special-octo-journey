# MP4 → 3GP Converter (Server-side, Railway এর জন্য)

এটি একটি Flask ব্যাকএন্ড যেটা **native ffmpeg** ব্যবহার করে সার্ভারে কনভার্সন করে। তাই:
- বড় ভিডিও ফাইলও সহজে হ্যান্ডেল হবে
- ব্রাউজার-বেসড (wasm) সলুশনের চেয়ে অনেক ফাস্ট
- ১-২ জন ইউজারের জন্য এটাই যথেষ্ট, কোনো queue/worker সিস্টেম লাগবে না

## ফাইল স্ট্রাকচার
```
.
├── app.py                 # Flask ব্যাকএন্ড, /convert এন্ডপয়েন্ট
├── templates/
│   └── index.html         # আপলোড UI
├── requirements.txt       # Python dependencies
├── Dockerfile             # ffmpeg + Python এনভায়রনমেন্ট সেটআপ
└── README.md
```

## Railway এ ডিপ্লয় করার নিয়ম
1. এই সব ফাইল একটি GitHub রিপোতে পুশ করুন (ফোল্ডার স্ট্রাকচার ঠিক রেখে, `templates/index.html` অবশ্যই `templates` ফোল্ডারের ভিতরে থাকতে হবে)।
2. [railway.app](https://railway.app) এ গিয়ে **New Project → Deploy from GitHub repo** সিলেক্ট করুন।
3. Railway নিজেই `Dockerfile` ডিটেক্ট করে বিল্ড করবে (Nixpacks না, Dockerfile ব্যবহার হচ্ছে কারণ ffmpeg ইনস্টল করা লাগবে)।
4. Deploy হয়ে গেলে Railway একটা পাবলিক URL দেবে (Settings → Generate Domain)।
5. এই URL-ই আপনার লাইভ কনভার্টার — সরাসরি ব্রাউজারে খুলে ব্যবহার করতে পারবেন।

## কীভাবে কাজ করে
- ইউজার ভিডিও আপলোড করে, `/convert` এন্ডপয়েন্টে POST হয়
- সার্ভারে `ffmpeg` কমান্ড রান হয়ে ভিডিওকে ছোট রেজোলিউশনে (QCIF/SQCIF/CIF) H.263 ভিডিও + AAC অডিও দিয়ে `.3gp` তে কনভার্ট করে
- যদি প্রাইমারি কমান্ড ফেল করে, ফলব্যাক হিসেবে MPEG-4 ভিডিও দিয়ে আবার চেষ্টা করে
- কনভার্ট হওয়া ফাইল সরাসরি ডাউনলোড রেসপন্স হিসেবে ইউজারকে পাঠানো হয়

## সেটিংস যেগুলো দরকার হলে বদলাতে পারেন
- `app.py` তে `MAX_CONTENT_LENGTH` — আপলোড সাইজ লিমিট (এখন 1GB সেট করা আছে)
- `run_ffmpeg()` এর `timeout=1800` — খুব বড় ভিডিও হলে বাড়াতে পারেন
- `Dockerfile` এর `gunicorn --timeout 600` — Railway এর রিকোয়েস্ট টাইমআউট, দরকারে বাড়ান

## সত্যি কথা (Honest note)
- এখানে **AMR-NB** (আসল পুরনো 3GP অডিও কোডেক) ব্যবহার করা হয়নি, কারণ Debian/Ubuntu এর ডিফল্ট ffmpeg বিল্ডে `libopencore_amrnb` লাইসেন্স ইস্যুর কারণে থাকে না। এর বদলে **AAC** অডিও ব্যবহার করা হয়েছে, যা আধুনিক ও কিছু পুরনো বাটন ফোন (KaiOS-ভিত্তিক, Jio Phone টাইপ) উভয়েই চলে। যদি আপনার টার্গেট ফোন খুবই পুরনো (Symbian S40 এর মতো) হয় এবং শুধু AMR অডিও সাপোর্ট করে, তাহলে ffmpeg কে সোর্স থেকে `--enable-libopencore-amrnb` ফ্ল্যাগ দিয়ে বিল্ড করতে হবে — এটা করা সম্ভব কিন্তু Dockerfile বড় ও বিল্ড টাইম বেশি হবে। প্রয়োজন হলে বলুন, আমি সেই ভার্সনও বানিয়ে দিতে পারি।
- ১-২ জন ইউজারের জন্য Railway এর ফ্রি/স্টার্টার প্ল্যানই যথেষ্ট হবে। ট্রাফিক বাড়লে প্ল্যান আপগ্রেড লাগবে।
